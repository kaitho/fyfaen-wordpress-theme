# FYFAEN Theme Release Notes

## 0.5.0

The presentation layer is now feature-complete for the first staging milestone: homepage, shop/archive, product presentation, cart styling and checkout styling are covered.

Commerce boundaries remain strict. The theme does not implement payment processing, order creation, refunds, gateway API calls or custom checkout transactions.

Before production activation, install the theme on staging and run `docs/QA-CHECKLIST.md` end to end with the site's real WooCommerce, Stripe and Vipps/MobilePay configuration.
